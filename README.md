# 자기장 서바이벌

줄어드는 자기장을 피해 3분을 버티는 웹 미니게임. 규칙 설계와 로그 기반 밸런스 조정 과정을 보여주려고 만들었다.

200x200m 지도를 걸어 다니고(방향키/WASD, 폰은 화면을 누른 채 밀기), 화면은 캐릭터를 따라가며, 우측 상단 미니맵에 자기장 원과 아이템이 보인다. 자기장은 원으로 줄어들고 10초 전에 다음 원이 점선으로 예고된다. 수치는 `src/config.js`, 변경 이력은 `docs/balance-log.md`에 있다.

## 실행

```
python -m http.server 8765
```

브라우저에서 `http://localhost:8765/` 를 연다. 빌드 도구와 서버 코드는 없다.

- `?p=A` 플레이어 라벨(기본 `self`). 이름 대신 A, B, C만 쓴다.
- `?seed=N` 첫 판 시드(기본 1). n번째 판은 `seed + n - 1`을 쓰므로 플레이어와 버전이 달라도 같은 번호의 판은 같은 조건이다.

## 기록과 리포트

결과 화면의 "기록 복사"를 누르면 한 판이 JSON 한 줄로 복사된다. 받은 줄을 파일에 모아 집계한다.

```
node tools/report.mjs logs/v0.1.jsonl
```

- 모든 비율은 분모와 함께 나온다.
- 판 수가 30 미만이면 해석은 [추정], 기록이 없으면 [미확인].
- 플레이어가 `self`뿐이면 "자체 플레이"로 표시한다.

## 밸런스 수정 규칙

`src/config.js`의 값만 바꾸고 `version`을 올린다. 한 번에 수치 하나만 바꾸고, "수정 전 / 수정 후 / 이유 / 바꾼 뒤 기록"을 남긴다.
